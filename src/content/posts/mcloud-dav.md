> 项目地址：**https://github.com/lastcyh/mcloud-dav** · MIT 协议 · 跑在 Cloudflare Workers 免费层，不需要服务器
>
> 这篇讲讲它是什么、怎么用；完整的部署参数和配置细节以仓库 README 为准。

## 前言

起因很简单：在网上找到一些移动云盘（139.com）的分享链接，不想转存——没开会员也没空间。后来想到网页上明明可以直接下载，为什么不把链接批量提取出来，做成 WebDAV 直接挂载？于是就有了这个项目。

最终方案：**GitHub 负责清洗，Cloudflare Worker 负责协议与服务**，全程免费层。

## 1. 两个推翻假设的实测

动手前有两个问题我觉得是"大概率不行"的，实测结果完全相反。

**直链不绑定 IP。** 移动云的下载直链本质是 EOS 对象存储的 S3 预签名 URL（`X-Amz-Expires=900`，15 分钟有效），签名只包含主机和时间，**根本不看访问者 IP**。所以 Worker 在境外解析直链、302 给境内客户端直连移动云机房的链路完全成立，视频流量一点不过代理。

**风控拦的是 IP 不是账号。** 联调时反复碰到 `9530 功能参数值非法`，一度以为是请求构造错了——其实是 139 对部分数据中心出口 IP 的风控，同一个请求换个出口重试就能过。Worker 里对这类错误做了三次退避重试，账号层面至今零异常。

协议本身没有从零逆向，站在 [OpenList](https://github.com/OpenListTeam/OpenList) 的 `139Yun` 驱动肩膀上整理出来的：列目录和取直链的请求体都是 `base64(IV + AES-128-CBC(排序JSON))`，令牌刷新是一个 XML 接口。

## 2. 怎么部署

1. 打开 [仓库 README](https://github.com/lastcyh/mcloud-dav)，点 **Deploy to Cloudflare** 按钮，确认后 Cloudflare 会自动创建 KV 和 Worker；
2. 打开分配的 Worker 地址，自动进入配置向导——粘贴一个 **139 Authorization**（登录 yun.139.com 后 F12 从请求标头里复制，README 里有逐步说明），再设一个 WebDAV 的用户名密码，保存；
3. 访问 `/admin`，把你的分享链接贴进去，格式是 `分类/标题 | 链接`，一行一条。

到这里就部署完了。令牌约 30 天有效，Worker 会在到期前自动续期，平时不用管。

## 3. 怎么添加分享

**少量**：就在 `/admin` 网页上贴，保存即生效。

**大量**：把包含链接的 Markdown/文本放进仓库 `data/` 目录（格式参考示例文件），跑一下 `clean_links.py` 并上传；或者配好 Secrets 后让 GitHub Actions 每天自动清洗推送。

脚本会自动提取全部链接（兼容被 Markdown 拆碎的）、按 ID 去重、按文档标题层级建目录、把 `4K/1080P/内封简中` 这类噪音从名字里剥掉。目录长什么样完全由你的标题层级决定，一行写多个链接还可以把多条分享绑到同一个目录。

## 4. 怎么使用

WebDAV 地址就是 Worker 地址本身，账号密码是配置向导里设置的（忘了打开 `/admin` 就能看到）。Infuse / nPlayer / Kodi 添加共享填进去就行；rclone 也是标准配置。

播放视频时 Worker 会实时解析一条移动云直链并 302 过去，流量直连移动云机房，不经过 Cloudflare。另外还提供一个 `/link?path=...` 直链接口，给下载工具和脚本用。

## 5. 工程上的取舍

- **缓存克制**：目录三层缓存（内存 → KV 7 天 → SWR 后台刷新），预热任务只补缺、绝不主动刷新——免费档 KV 每天只有 1000 次写入，稳态写入必须趋近于零；
- **调用克制**：对 139 只用"列目录"这一个只读接口，预热每日硬上限 2000 次，摊下来比人在网页上翻文件夹的量级还低；
- **认证克制**：同一 IP 连续失败 5 次锁 15 分钟（内存级），失败带随机延迟。第一版把计数写 KV，很快意识到爆破者能反过来刷爆你的配额，于是全撤了；
- **个人使用定位**：地址和凭据不要公开分发，所有访客消耗的都是你自己的额度。

## 6. 局限

直链 15 分钟有效（已内置缓存与重试）；只读，不支持上传转存；令牌彻底失效时要重新抓一次（约 30 天一次的频率）；不存储任何音视频文件，仅做链接整理和直链跳转，请遵守当地法律法规。
